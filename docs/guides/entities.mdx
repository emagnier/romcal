Romcal includes a database of liturgical entities (saints, blesseds, feasts) that you can search and lookup.

## Lookup by ID

If you know the exact ID of an entity, you can look it up directly.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">

```typescript
import { Romcal } from 'romcal';

const romcal = new Romcal();
const francis = romcal.getEntity('francis_of_assisi');

console.log(francis.fullname); // "Saint Francis of Assisi"
```

  </TabItem>
  <TabItem label="Python">

```python
from romcal import Romcal

romcal = Romcal()
francis = romcal.get_entity("francis_of_assisi")

print(francis.fullname)  # "Saint Francis of Assisi"
```

  </TabItem>
  <TabItem label="Rust">

```rust
use romcal::Romcal;

let romcal = Romcal::new();
let francis = romcal.get_entity("francis_of_assisi");

println!("{}", francis.fullname); // "Saint Francis of Assisi"
```

  </TabItem>
</Tabs>

## Fuzzy Search

Search for entities by name with fuzzy matching.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">

```typescript
import { Romcal } from 'romcal';

const romcal = new Romcal();
const results = romcal.searchEntities('francis');

for (const result of results) {
  console.log(`${result.id}: ${result.fullname} (score: ${result.score})`);
}
```

  </TabItem>
  <TabItem label="Python">

```python
from romcal import Romcal

romcal = Romcal()
results = romcal.search_entities("francis")

for result in results:
    print(f"{result.id}: {result.fullname} (score: {result.score})")
```

  </TabItem>
  <TabItem label="Rust">

```rust
use romcal::Romcal;

let romcal = Romcal::new();
let results = romcal.search_entities("francis");

for result in &results {
    println!("{}: {} (score: {})", result.id, result.fullname, result.score);
}
```

  </TabItem>
</Tabs>

## Search Filters

You can filter search results by various criteria:

- **type**: Entity type (SAINT, BLESSED, etc.)
- **sex**: MALE or FEMALE
- **canonization_level**: CANONIZED, BEATIFIED, etc.
- **titles**: Filter by title (MARTYR, VIRGIN, DOCTOR_OF_THE_CHURCH, etc.)

## Entity Properties

Each entity includes:

| Property             | Description                            |
| -------------------- | -------------------------------------- |
| `id`                 | Unique identifier                      |
| `fullname`           | Full display name                      |
| `name`               | Short name                             |
| `canonization_level` | SAINT, BLESSED, etc.                   |
| `titles`             | Array of titles (MARTYR, BISHOP, etc.) |
| `date_of_death`      | Year or full date of death             |
