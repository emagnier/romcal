## Features

<CardGrid stagger>
  <Card title="Perpetual Calendar" icon="open-book">
    Calculate liturgical dates for **any year** following official Church norms ([GIRM](/reference/girm),
    [GNLY](/reference/gnly), [GILH](/reference/gilh)).
  </Card>
  <Card title="Global Coverage" icon="translate">
    **60+ calendars** for countries, dioceses, and religious communities. **10+ languages** with easy support for new
    locales.
  </Card>
  <Card title="Rich Metadata" icon="information">
    **Complete martyrology**: saints, blesseds, feasts, places, and events with biographical info, liturgical colors,
    ranks, and cycles.
  </Card>
  <Card title="Multi-Platform" icon="rocket">
    **High-performance Rust** core with native bindings for TypeScript, Python, and CLI. Clean APIs, JSON schemas, and
    tree-shaking support.
  </Card>
</CardGrid>
